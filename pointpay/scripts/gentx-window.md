# Gentx window (mainnet `pointpay-1`)

**Status:** Not open. Dates will be posted on https://github.com/pointpay-hub/pointpay-chain

When open:

1. Build `pointpayd` from the announced tag  
2. Follow [MAINNET_OPERATORS.md](../../MAINNET_OPERATORS.md)  
3. Submit gentx JSON via PR to `gentxs/` (or the form linked in the release)  
4. Coordinators run `collect-gentxs.sh` → publish final genesis SHA  

Do **not** submit gentxs against `pointpay-dedicated-1` (testnet).
